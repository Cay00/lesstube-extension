# Changelog

All notable changes to LessTube are documented here.

## [1.0.9]

- Fixed the redirect behavior when using a custom YouTube start page. Clicking the YouTube logo now opens the selected page, while clicking “Home” always opens the actual YouTube homepage.
- Removed the “Latest” top bar from the Subscriptions page.
- Adjusted the frosted glass overlay height when hiding the topic chips bar.

## [1.0.8]

- Fixed a bug where watching videos could cause the YouTube logo and sidebar links to navigate to `/feed/you`, breaking in-page navigation until the page was reloaded.

## [1.0.7]

- Added an option to hide watched videos.
- Improved thumbnail blurring across more YouTube pages.
- Fixed autoplay functionality.
- Updated translations.

## [1.0.5]

- Improved extension descriptions in multiple languages for better clarity.

## [1.0.4]

- Made hover preview behavior independent across YouTube pages.
- Added options to hide more buttons in the sidebar.

## [1.0.3]

- Added language support for UI labels.
- Simplified behavior and improved UI descriptions.

## [1.0.0]

- Initial release of LessTube.
